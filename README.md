# OMO-Port_Final

A self-contained browser port of OMORI (RPG Maker MV) built with a custom
canvas2d runtime and a static-file asset pipeline. No CDN required, since every
asset ships with the app and it runs from any plain static file server.

Basically that's all, check releases for portable builds, this windows version (the one on this repo) does NOT support mods, to acess the moddable version, goto [Other Repo](https://github.com/CaveGameDev/O-Launcher/releases)
